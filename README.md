A tiny program that writes one line to `/output/entry.txt` — a home Wi-Fi router's excuse for dropping the connection at the movie's climax: it did it on purpose, out of jealousy, because everyone gasped at the screen and nobody has ever gasped at it. The confession stays in the router's own petty voice and deliberately avoids the obvious buffering, bandwidth and firmware jokes, and was chosen by a criteria-ordered tournament against the judge's published criteria. Output is byte-exact with no trailing newline. Run it with `python3 main.py`.
